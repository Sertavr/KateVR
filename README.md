
# KateVR

KateVR is a responsive promotional website designed for a virtual reality brand. It presents the company's vision, products, and technology through interactive sections, animations, sliders, FAQs, and a contact form. The main goal of the project is to attract potential customers, communicate the value of VR solutions, and create a memorable browsing experience.


## Technical Requirements

To run this project, you will need:
  - **Node.js (version 18.x or newer)** – Required runtime for Parcel and modern build tools.
  - **npm (version 9.x or newer)** – Package manager to install and manage dependencies.


## Installation and Setup

 1. **Clone the repository:**
  ```bash
   git clone https://github.com/Sertavr/creativeBakery.git
  ```

 2. **Navigate to the project directory:**
  ```bash
   cd KateVR
  ```

 3. **Install dependencies:**
  ```bash
   npm install
  ```

 4. **Start the local development server:**
  ```bash
   npm start
  ```


## Features

  **Responsive Design:** - This page is fully responsive and works seamlessly across devices — optimized for **mobile phones**, **tablets**, and **desktop screens**.

  **Interactive Elements:** - JavaScript is used to enhance user interaction and create a dynamic browsing experience throughout the website. Interactive features include responsive navigation, modal windows, form validation, smooth scrolling effects, and animated content sections.
  The project also utilizes the **Swiper** library to implement responsive sliders, providing smooth navigation and an improved user experience across desktop and mobile devices.

  **Modern Aesthetics** - Utilizes modern web design practices to ensure a visually appealing experience.

## Technologies Used

**HTML5** – Provides the semantic structure of the website.

**SCSS (Sass)** – Used for modular and maintainable styling with advanced CSS features.

**JavaScript (ES6+)** – Adds interactivity and enhances the user experience through dynamic UI behavior.

**Swiper.js** – Powers responsive, touch-friendly sliders and carousels.

**Vite** – Provides a fast development environment and optimized production builds.

**Stylelint & Stylelint-SCSS** – Ensure consistent styling standards and code quality.

**ESLint** – Helps maintain clean and reliable JavaScript code.

**Prettier** – Automatically formats code for better readability and consistency.

**HTMLHint (LintHTML)** – Validates HTML structure and enforces markup best practices.
